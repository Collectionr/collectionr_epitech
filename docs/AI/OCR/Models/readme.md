# AI/OCR — TCG Card Scanning Evaluation

## Objective

Evaluate existing OCR models for TCG card scanning and determine whether they meet our requirements without fine-tuning.

## Evaluation

For each tested model, document:

* **Model tested**
* **OCR accuracy**
* **Scan time per card**
* **VRAM consumption**
* **Advantages / limitations**
* **Fine-tuning required:** Yes / No

## Documentation

* Use the .ipynb file to document the testing steps and produce the post-processing.

* Use the README.md to provide a short summary of the steps performed and the results obtained.

## Conclusion

Compare the tested models and determine:

* Is the OCR accuracy sufficient for our needs?
* Is the scanning time acceptable?
* Is the VRAM consumption acceptable?
* Is fine-tuning necessary?
* Which model is the best candidate for the TCG OCR pipeline?
