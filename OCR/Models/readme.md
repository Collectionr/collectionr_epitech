# IA/OCR — Évaluation de la numérisation de cartes TCG

## Objectif

Évaluer les modèles OCR existants pour la numérisation de cartes TCG et déterminer s'ils répondent à nos besoins sans fine-tuning.

## Évaluation

Pour chaque modèle testé, documenter :

* **Modèle testé**
* **Précision de l'OCR**
* **Temps de scan par carte**
* **Consommation VRAM**
* **Avantages / limites**
* **Fine-tuning nécessaire :** Oui / Non

## Documentation

* Utiliser le fichier .ipynb pour documenter les étapes de test et produire le post-traitement.

* Utiliser le README.md pour fournir un court résumé des étapes effectuées et des résultats obtenus.

## Conclusion

Comparer les modèles testés et déterminer :

* La précision de l'OCR est-elle suffisante pour nos besoins ?
* Le temps de scan est-il acceptable ?
* La consommation VRAM est-elle acceptable ?
* Le fine-tuning est-il nécessaire ?
* Quel modèle est le meilleur candidat pour le pipeline OCR TCG ?
