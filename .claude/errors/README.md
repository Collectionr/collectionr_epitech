# Base d'erreurs résolues

Un fichier par erreur non triviale rencontrée sur le projet, pour ne jamais re-débugger deux fois.

Format : `<slug>.md` avec trois sections — **Symptôme** (message exact), **Diagnostic** (comment on a trouvé), **Solution**.

Avant de débugger longuement une erreur : vérifier si elle est déjà documentée ici.
Après avoir résolu une erreur qui a pris > 15 min : l'ajouter ici.
