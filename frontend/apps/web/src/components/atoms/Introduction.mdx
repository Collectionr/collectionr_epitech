# Atoms

Les atomes sont les composants élémentaires de l'interface.
Placer leurs stories à côté des composants dans ce dossier, avec un titre `NomDuComposant` (le groupe Atoms est ajouté automatiquement).
Les tokens et leurs démonstrations sont regroupés dans **Fondations**.
Les composants de ce niveau seront ajoutés dans leurs tickets respectifs.
