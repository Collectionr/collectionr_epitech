# Organisms

Les organismes regroupent des composants pour former une section complète d'interface.
Placer les stories à côté des composants dans ce dossier, avec un titre `NomDuComposant` (le groupe Organisms est ajouté automatiquement).
Les composants de ce niveau seront ajoutés dans leurs tickets respectifs.
