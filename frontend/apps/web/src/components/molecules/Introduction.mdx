# Molecules

Les molécules assemblent des atomes pour répondre à un besoin d'interface précis.
Placer les stories à côté des composants dans ce dossier, avec un titre `NomDuComposant` (le groupe Molecules est ajouté automatiquement).
Les composants de ce niveau seront ajoutés dans leurs tickets respectifs.
