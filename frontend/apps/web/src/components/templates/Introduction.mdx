# Templates

Les templates définissent l'agencement des sections d'une page.
Placer les stories à côté des composants dans ce dossier, avec un titre `NomDuComposant` (le groupe Templates est ajouté automatiquement).
Les composants de ce niveau seront ajoutés dans leurs tickets respectifs.
